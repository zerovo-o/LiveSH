## 4. 大模型 API 人员：接入 AI 建议

### 当前已经完成的占位

前端展示组件已创建：

```text
frontend/src/components/AIAdvicePanel.tsx
```

该组件已经接入页面：

```text
frontend/src/App.tsx
```

位置在：

```text
区域选择与详情
可视化分析
AI 居住建议
```

前端请求接口：

```text
POST /api/ai/advice
```

请求体：

```json
{
  "district": "浦东"
}
```

当选择“全部区域”时，前端会传：

```json
{
  "district": null
}
```

### 后端占位位置

接口位置：

```text
backend/app/main.py
```

当前接口：

```python
@app.post("/api/ai/advice", response_model=AIAdviceOut)
def ai_advice(payload: AIAdviceRequest, db: Session = Depends(get_db)):
```

Prompt 与大模型调用占位：

```text
backend/app/ai_advice.py
```

核心函数：

```python
build_livability_prompt(metric: DistrictMetric) -> str
generate_ai_advice(metric: DistrictMetric) -> tuple[str, str, bool]
```

现在 `generate_ai_advice` 返回的是规则占位文本，不是真实大模型结果。

### 需要完成的工作

1. 在 `backend/.env` 中增加大模型配置，例如：

```text
LLM_API_KEY=你的 API Key
LLM_BASE_URL=你的模型服务地址
LLM_MODEL=模型名称
```

2. 在 `backend/app/config.py` 中读取这些配置。

3. 在 `backend/app/ai_advice.py` 的 `generate_ai_advice` 中调用真实模型 API。

4. 保持接口返回格式不变：

```json
{
  "district": "浦东",
  "prompt": "...",
  "advice": "...",
  "is_placeholder": false
}
```

5. 接入真实模型后，将 `is_placeholder` 改为 `False`。

### Prompt 当前内容

当前 prompt 已包含：

- 区名
- 平均挂牌单价
- 平均挂牌总价
- 房源数量
- POI 总数
- 购物、交通、医疗、休闲、企业、住宅 POI
- 商圈活跃度
- 房价标准化
- 活跃度标准化
- 宜居性评分

要求模型输出：

1. 一句话结论
2. 主要优势
3. 可能短板
4. 适合人群
5. 需要谨慎解释的数据局限

### 注意事项

- 不要把 API Key 写进代码。
- 不要把 `.env` 提交到仓库。本地再.env中写KEY，上传github时再.env.example中加一行API KEY的变量名=...
- 如果大模型接口失败，后端应该返回可理解的错误，或者保留占位建议作为降级。
- 前端已经能展示 `advice` 字段，原则上不需要改前端接口。

### 验收标准

- `POST /api/ai/advice` 能返回真实模型生成的建议。
- 前端 `AI 居住建议` 卡片能展示真实建议。
- `is_placeholder` 为 `false`。
- 模型建议不能编造项目数据之外的具体事实。
