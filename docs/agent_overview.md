# Agent 概览

## 作用
个性化区域/小区/房源推荐，不是聊天机器人。

## 输入
- 预算（万元）
- 目标面积（平方米）
- 工作地址
- 通勤方式（公交 / 驾车）
- 最大通勤时间（分钟）
- 偏好权重

## 流程
1. 先按预算和项目已有指标筛选候选房源。
2. 再计算区域/小区的规则分。
3. 对少量 Top 候选调用高德通勤接口。
4. 通勤失败时使用距离估算兜底。
5. LLM 只负责重排和文案润色，不负责全权打分。

## 评分
- 房源分：预算 + 通勤 + POI 偏好 + POI 子类 + 可达性 + E2SFCA + 校准分
- 小区分：与房源类似，但聚合到小区层

## 输出
- `district`
- `score`
- `commute_minutes`
- `avg_price`
- `avg_total_price`
- `house_count`
- `reason`
- `risks`

## 当前限制
- 高德 geocode 可能失败
- 通勤 API 可能受限
- 失败时接口仍会返回结果，但通勤分可能为 0 或估算值
