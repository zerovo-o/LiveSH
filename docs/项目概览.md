# 项目概览

LiveSH 是一个面向上海居住选择分析的 WebGIS 可视化系统。项目将二手房挂牌数据、POI 设施数据和街镇边界放入同一套空间分析流程，从**行政区、街道/镇、房源点周边**三个层次观察“住得是否划算、生活是否方便”。

## 目标问题

```text
在上海，哪些区域住得更划算，也更方便？
```

## 当前功能

- 产品化首屏：说明项目主题、数据对象和打分逻辑，并支持平滑进入地图 GIS。
- 区级专题地图：支持查看校准评分、生活圈、房价、POI 总量和商圈活跃度。
- 推荐区域 Top5：按 `calibrated_score_life_circle` 排序，展示默认推荐结果。
- 区域详情：展示房价、房源、POI、供需可达性、样本可信度等指标。
- 街道/镇精细分析：可按区筛选、搜索街镇，并查看生活圈、最近交通/医疗距离、供需可达性等信息。
- 可视化分析：提供城市概览、设施结构、关系洞察和评分模型四组图表。
- AI 居住建议：接口和前端模块已具备，当前返回规则占位结果，后续可接入真实大模型。

## 技术栈

- 后端：FastAPI、SQLAlchemy、pandas、SciPy、pyproj、pyshp
- 数据库：默认 SQLite；可通过 `DATABASE_URL` 切换 PostgreSQL
- 前端：React、Vite、TypeScript、Tailwind CSS、shadcn/ui、ECharts
- GIS：高德地图 JS API；前端地图统一使用 GCJ-02 坐标

## 课程展示重点

本项目现在不只是比较“哪里 POI 多、哪里房价低”，而是进一步回答：

1. 哪些区域房价压力更高？
2. 哪些区域设施供给和可达性更好？
3. 哪些区域在供需匹配和生活圈覆盖后，仍然具有较好的综合表现？
4. 区级结论落到街道/镇层面后，是否依旧成立？

地图负责提供空间直觉，图表负责解释指标关系，街镇分析负责补足更细粒度的落点。
