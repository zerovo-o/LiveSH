# 前端功能说明

LiveSH 前端位于 `frontend/`，使用 React + Vite + TypeScript 实现，UI 基于 Tailwind CSS 与 shadcn/ui，图表使用 ECharts。

## 启动方式

```bash
cd frontend
corepack pnpm install
corepack pnpm run dev
```

默认地址：

```text
http://localhost:5173
```

## 页面结构

页面当前为下滑式结构：

1. 首屏产品介绍
2. 地图 GIS 主模块
3. 区域选择与详情
4. 街道/镇精细分析
5. 可视化分析模块
6. 个性化 Agent 推荐模块

## 首屏

首屏展示：

- 项目品牌名 `LiveSH`
- 项目目标：让地图回答哪里住得更划算、更方便
- 数据对象：二手房、POI、街镇边界
- 打分逻辑：稳健评分、设施供需充足度、校准评分与生活圈评分
- 双箭头入口：点击后平滑滚动到地图 GIS

## 地图 GIS

地图默认展示校准评分，并支持切换：

- 校准评分
- 生活圈
- 房价
- POI 总量
- 商圈活跃度

地图可叠加街道/镇边界，并在区级或街镇级空间单元上显示专题着色。

## 推荐区域 Top5

推荐区域基于 `calibrated_score_life_circle` 从高到低排序，取前 5 个区。

展示内容：

- 排名
- 区名
- 校准评分
- 平均房价

## 区域详情

区域详情展示：

- 平均房价、平均总价、房源数量
- 各类 POI 数量与活跃度
- 校准评分
- 设施供需充足度
- 样本可信度
- 单区下额外展示房价标准化和活跃度标准化

## 街道/镇精细分析

街镇模块支持：

- 按行政区筛选
- 搜索街道/镇
- 展示达到房源门槛的街镇推荐结果
- 查看生活圈总分、5/10/15 分钟分项、覆盖率、设施供需充足度、最近交通/医疗距离等指标

当前推荐门槛为：

```text
house_count >= 50
```

## 可视化分析

模块包含：

- 城市概览
- 设施结构
- 关系洞察
- 评分模型

图表覆盖排名、结构、相关性、象限关系、雷达对比和评分分布等主题。

## AI 居住建议

`AIAdvicePanel` 会调用：

```text
POST /api/ai/advice
```

当前后端返回规则生成的占位建议，并用“待接入大模型”标识当前状态。后续接入真实模型后，前端无需大改即可继续复用同一接口。

当前主页面未挂载 `AIAdvicePanel`，保留该组件和后端接口作为后续扩展能力。

## 个性化 Agent 推荐

`PersonalizedAgentPanel` 当前已挂载在页面底部，会调用：

```text
POST /api/agent/recommend-houses
```

用户可输入预算、目标面积、工作地点、通勤方式、最大通勤时间，以及医疗、教育、休闲等偏好权重。前端展示后端返回的小区推荐、平均单价、平均总价、通勤时间、推荐理由、预算/POI/通勤分和房源 ID。

该模块依赖后端高德 Web 服务 Key 做地址解析和路线估计；如果后端配置了 LLM 相关环境变量，还会在规则打分后对候选结果做辅助重排。
