# 前端功能说明

LiveSH 前端位于 `frontend/`，使用 React + Vite + TypeScript 实现，UI 基于 Tailwind CSS 与官方 shadcn/ui 组件。

## 启动方式

```bash
cd frontend
corepack pnpm install
corepack pnpm run dev
```

Vite 默认地址：

```text
http://localhost:5173
```

生产构建：

```bash
cd frontend
corepack pnpm run build
```

## 页面结构

页面当前为下滑式结构：

1. 首屏产品介绍
2. 地图 GIS 主模块
3. 区域选择与详情
4. 可视化分析模块

## 首屏

首屏展示：

- 项目品牌名 `LiveSH`
- 项目目标：让地图回答哪里住得更划算、更方便
- 数据对象：二手房挂牌价格与购物、交通、医疗、休闲、企业等 POI
- 打分逻辑：商圈活跃度与房价标准化后相减
- 双箭头入口：点击后平滑滚动到地图 GIS

## 推荐区域 Top5

推荐区域根据 `livability_score` 从高到低排序，取前 5 个区。

展示内容：

- 排名
- 区名
- 综合评分
- 平均房价

点击推荐区域后，会同步更新：

- 地图选中区
- 区域详情
- 图表中的高亮标记

## 区域选择与详情

区域选择支持：

- 全部区域
- 单个区

详情面板展示：

- 平均房价
- 平均总价
- 房源数量
- POI 总数
- 购物、交通、医疗、休闲、企业、住宅 POI 数
- 商圈活跃度
- 宜居评分
- 单区情况下额外展示房价标准化与活跃度标准化

选择“全部区域”时，面板展示全市汇总或平均指标。

## shadcn/ui 说明

本项目使用官方 shadcn/ui 组件，组件配置位于 `frontend/components.json`。新增组件请使用官方 CLI，例如：

```bash
cd frontend
corepack pnpm dlx shadcn@latest add badge
```
