# LiveSH 文档目录

本文档是 `docs/` 目录入口。当前 LiveSH 已从早期区级简单评分，演进为同时覆盖区级、街镇级、房源点周边和个性化推荐的 WebGIS 分析系统。

## 推荐阅读顺序

1. [数据工程与指标模型](数据工程与指标模型.md)：数据入口、清洗入库、评分层次和派生结果。
2. [后端接口说明](后端接口说明.md)：FastAPI 启动方式、环境变量和当前 API。
3. [前端功能说明](前端功能说明.md)：页面结构、地图、图表、街镇分析和个性化 Agent。
4. [地图 GIS 与高德配置](地图GIS与高德配置.md)：高德 Key、坐标体系和路线服务配置。
5. [可视化分析说明](可视化分析说明.md)：当前图表模块、AI 图表结论和街镇级图表。
6. [交互联动与扩展方向](交互联动与扩展方向.md)：地图、图表、街镇、小区和 Agent 的联动关系。
7. [真实路网步行时间升级说明](真实路网步行时间升级说明.md)：杨浦区真实步行路线抽样试算方案与输出。
8. [metrics.py 指标公式说明](metrics.py指标公式说明.md)：指标公式细节。本次文档同步不修改该文件。

## 当前主线

```text
数据清洗与空间匹配
  -> 区级 / 街镇级指标
  -> 房源点可达性
  -> E2SFCA 风格设施供需充足度
  -> 5/10/15 分钟生活圈
  -> 样本可信度校准
  -> 地图、图表、街镇明细和个性化 Agent 推荐
```

默认地图着色、Top5 推荐和区级排行榜仍以 `calibrated_score_life_circle` 为主。杨浦区真实路网步行时间目前是试算和对比能力，通过专门接口和街镇图表展示，不直接替换全市默认评分。
