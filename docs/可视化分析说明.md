# 可视化分析说明

可视化分析模块是 LiveSH 的课程展示重点，参考了数据分析与可视化课程案例中的常见方法：柱状图、饼图、堆叠柱状图、气泡散点图、热力图、雷达图和多变量对比。

当前分为四个模块。

- 哪些区房价最高？
- 哪些区综合评分最高？

- 哪些区属于“高便利、低成本”或“高便利、高成本”？

## 图表方法与课程案例对应

- 排名类问题：柱状图、条形图
- 占比类问题：饼图
- 结构类问题：堆叠柱状图
- 关系类问题：散点图、气泡图、象限图
- 相关性问题：热力图
- 多指标对比：雷达图、平行坐标
- 分布问题：评分区间分布图
