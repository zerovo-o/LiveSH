# 后端接口说明

LiveSH 后端位于 `backend/`，使用 FastAPI 提供数据服务，使用 SQLAlchemy 管理数据库模型。

## 启动方式

```bash
cd backend
python3 -m pip install -e ".[postgres]"
python3 -m app.process_data
python3 -m uvicorn app.main:app --reload
```

默认数据库为：

```text
backend/livability.db
```

如需切换 PostgreSQL，可在 `backend/.env` 中设置 `DATABASE_URL` 后重新入库。

## 环境变量

```text
DATABASE_URL=sqlite:///./livability.db
AMAP_WEB_SERVICE_KEY=填入你的高德 Web 服务 Key
LLM_API_KEY=
LLM_BASE_URL=
LLM_MODEL=
LLM_RERANK_ENABLED=
LLM_RERANK_WEIGHT=0.3
LLM_RERANK_TIMEOUT_SEC=60
LLM_RERANK_MAX_CANDIDATES=12
RECOMMENDER_VERSION=v3
```

`AMAP_WEB_SERVICE_KEY` 用于个性化推荐中的工作地点地理编码和路线时间估计。LLM 相关变量为空时，个性化推荐仍会返回规则模型结果，只是不启用候选小区和房源的大模型重排。

## 主要接口

### `GET /health`

健康检查接口。

### `GET /api/districts`

返回全部区级指标，默认按 `calibrated_score_life_circle` 降序排列。

### `GET /api/districts/{district}`

返回单个行政区指标。

### `GET /api/streets`

返回街道/镇指标列表，可使用查询参数按区过滤：

```text
GET /api/streets?district=浦东
```

### `GET /api/streets/{district}/{street}`

返回单个街道/镇指标。

### `GET /api/summary`

前端主面板使用的聚合接口，返回：

- `districts`：全部区级指标
- `poi_categories`：POI 类别占比
- `price_top10`：房价 Top10
- `shopping_top5`：购物数量 Top5
- `score_ranking`：按 `calibrated_score_life_circle` 排序的区级榜单
- `scatter`：图表使用的区级散点数据
- `recommendations`：房源样本数不少于 50 的推荐 Top5

### `GET /api/amap/shanghai-districts`

返回上海区级行政边界。

### `GET /api/amap/shanghai-streets`

返回本地街镇边界。

### `POST /api/ai/advice`

返回 AI 居住建议结果。

当前实现仍为占位逻辑：后端会根据区级指标构造 prompt，并返回规则生成的文本，同时 `is_placeholder=true`。后续可在 `backend/app/ai_advice.py` 中接入真实大模型服务。

### `POST /api/agent/recommend-houses`

返回个性化街镇、小区和房源推荐结果。请求参数包括：

- `budget_wan`：购房预算，单位万元
- `target_area`：目标面积，单位平方米
- `work_address`：工作地点文本地址
- `commute_mode`：通勤方式，支持 `transit` 和 `driving`
- `max_commute_minutes`：可接受最大通勤时间
- `top_streets`、`top_communities`、`top_houses_per_community`：返回数量控制
- `daily_life_weight`、`commute_facility_weight`、`medical_weight`、`education_weight`、`recreation_weight`、`employment_weight`：偏好权重
- `max_route_calls`：单次请求最多路线调用数

响应会返回：

- `work_location`：工作地点地理编码结果
- `streets`：街镇推荐
- `communities`：小区推荐、评分拆解、风险提示和房源 ID
- `summary`：候选房源数量、路线调用次数、LLM 重排是否启用等执行摘要
