# 后端接口说明

LiveSH 后端位于 `backend/`，使用 FastAPI 提供数据服务，使用 SQLAlchemy 管理数据库模型。

## 启动方式

推荐使用本机 Anaconda Python：

```bash
cd backend
/opt/anaconda3/bin/python3 -m pip install -e ".[postgres]"
/opt/anaconda3/bin/python3 -m app.process_data
/opt/anaconda3/bin/python3 -m uvicorn app.main:app --reload
```

默认会生成 `backend/livability.db`。如果要使用 PostgreSQL，修改 `backend/.env`：

```text
DATABASE_URL=postgresql+psycopg2://用户名:密码@127.0.0.1:5432/shanghai_livability
```

然后重新入库：

```bash
cd backend
/opt/anaconda3/bin/python3 -m app.process_data
```

## 环境变量

```text
DATABASE_URL=sqlite:///./livability.db
AMAP_WEB_SERVICE_KEY=填入你的高德 Web服务 Key
```

## 主要接口

### `GET /health`

健康检查接口。

返回示例：

```json
{
  "status": "ok"
}
```

### `GET /api/districts`

按宜居性评分返回所有区级指标。

主要用途：

- 区域列表
- 地图数据
- 排名数据

### `GET /api/districts/{district}`

返回单个区的指标。

示例：

```text
GET /api/districts/浦东
```

### `GET /api/summary`

前端 Dashboard 主接口。返回页面需要的汇总数据。

返回内容包括：

- `districts`：全部区级指标
- `poi_categories`：POI 类别占比数据
- `price_top10`：房价 Top10 区域
- `shopping_top5`：购物数量 Top5 区域
- `score_ranking`：宜居性评分排名
- `scatter`：散点图和多变量图使用的区级数据
- `recommendations`：推荐区域

### `GET /api/amap/shanghai-districts`

通过高德 Web 服务 Key 获取上海区级行政边界，作为前端地图行政区面的数据来源。

如果后端 Web 服务 Key 不可用，前端仍可尝试使用高德 JS API 的行政区查询能力，但稳定性取决于前端 Key 配置。
