# 交互联动与扩展方向

## 当前交互联动

当前联动逻辑：

1. 点击地图行政区，更新当前选中区
2. 点击推荐区域 Top5，更新当前选中区
3. 点击图表中的区域项，更新当前选中区
4. 区域下拉框切换后，地图、指标面板和图表同步更新
5. 街道/镇模块可跟随行政区筛选，并展示更细粒度结果
6. 小区列表随行政区、街镇和搜索关键词过滤
7. 可视化图表可生成 AI 结论，结论使用当前图表摘要数据
8. 个性化 Agent 推荐模块根据用户输入的预算、工作地点和偏好权重生成街镇、小区与房源推荐

## 联动目标

联动设计希望让用户围绕同一个区域连续切换观察角度：

- 地图回答“它在上海哪里、空间表现如何”
- 区域详情回答“它的核心指标是多少”
- 街道/镇模块回答“区级结论下钻后是否仍然成立”
- 小区列表回答“当前街镇里有哪些可进一步查看的居住单元”
- 图表回答“它为什么得分高或低”
- AI 图表结论回答“这张图中最值得解释的比较关系是什么”
- 个性化 Agent 推荐回答“在我的预算、通勤和偏好下，哪些小区与房源更值得优先看”
