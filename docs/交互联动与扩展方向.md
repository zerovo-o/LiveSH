# 交互联动与扩展方向

本文档说明 LiveSH 当前的交互联动逻辑，以及后续可以继续扩展的方向。

## 交互联动

当前联动逻辑：

1. 点击地图行政区，更新当前选中区。
2. 点击推荐区域 Top5，更新当前选中区。
3. 点击图表中的区域项，更新当前选中区。
4. 区域选择下拉框切换区域后，地图和图表同步高亮。
5. 选择“全部区域”后，区域详情展示全市汇总。

## 联动目标

联动设计的目标是让用户围绕同一个区域不断切换观察角度：

- 地图回答“它在上海哪里、空间上表现如何”。
- 区域详情回答“它的具体指标是多少”。
- 推荐区域回答“哪些区域综合表现靠前”。
- 可视化分析回答“它为什么得分高或低”。

## 后续可扩展方向

后续可以继续扩展：

- 引入街道级或网格级空间分析，提升空间分辨率。
- 使用真实区面积计算 POI 密度，而不是仅使用 POI 数量。
- 增加预算输入，输出推荐区域。
- 增加 KMeans 聚类，将上海各区划分为不同居住类型。
- 引入交通可达性或通勤时间数据，提升便利性指标质量。
- 对房价分布做箱线图或小提琴图，展示区内价格差异。
