# 交互联动与扩展方向

## 当前交互联动

当前联动逻辑：

1. 点击地图行政区，更新当前选中区
2. 点击推荐区域 Top5，更新当前选中区
3. 点击图表中的区域项，更新当前选中区
4. 区域下拉框切换后，地图、指标面板和图表同步更新
5. 街道/镇模块可跟随行政区筛选，并展示更细粒度结果
6. 个性化 Agent 推荐模块根据用户输入的预算、工作地点和偏好权重生成小区与房源推荐

## 联动目标

联动设计希望让用户围绕同一个区域连续切换观察角度：

- 地图回答“它在上海哪里、空间表现如何”
- 区域详情回答“它的核心指标是多少”
- 街道/镇模块回答“区级结论下钻后是否仍然成立”
- 图表回答“它为什么得分高或低”
- 个性化 Agent 推荐回答“在我的预算、通勤和偏好下，哪些小区与房源更值得优先看”

## 后续可扩展方向

- 让图表进一步支持街镇级下钻，而不只停留在区级
- 对街镇结果增加聚类、分型和解释标签
- 引入更真实的步行时间或路网数据，提升生活圈评分精度
- 继续增强个性化 Agent 推荐的解释能力、房源详情展示和候选过滤条件
- 将 AI 建议从占位逻辑升级为真实大模型生成，并加入可追溯解释
